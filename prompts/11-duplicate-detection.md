# v0.11 重复文件检测 Prompt

规划与提示词：DeepSeek-V4 Flash（agent: opencode），2026-08-23。

## 背景

你是一名资深 Electron + React + TypeScript 桌面应用工程师。请在现有 Vid Folder Browser 项目上进行 v0.11 增量开发。

本版本增加**精确重复视频检测**：在已扫描的当前根目录范围内，找出内容完全相同（字节级）的视频文件并按组展示。用于发现无意中复制多份、占用磁盘的重复文件。

重要规则：

- 开始前阅读 `PROJECT_MEMORY.md`、`PROMPT_VERSIONING.md`、README 和当前实现。
- 只做"精确重复"（哈希相同）；不做感知哈希（pHash）近似重复。
- 只读检测：本版本不提供删除/移动/合并操作（只允许定位与打开）。
- 检测对已扫描数据做增量利用（size 分组），不重新扫描文件系统。
- 大文件哈希可能较慢：必须支持进度与取消，且不得阻塞主线程与 UI 交互。
- 中文内容和源码统一使用 UTF-8。

## 当前已实现功能

- v0.1-v0.10 全部能力（含自动发布与更新检查）。
- 扫描结果已含每个视频的：路径、大小、修改时间、时长、分辨率（及 v0.8 的技术信息）。
- 当前浏览上下文：单一根目录（扫描 token 区分目录上下文）。

本版本的重新实现目标：无（纯增量）。

## 本版本目标

- 对当前扫描结果执行精确重复检测，输出重复组（组内 ≥2 个文件，内容哈希一致）。
- 检测面板展示重复组：组内每个文件的路径、大小、修改时间、时长；可点击定位（在文件夹树中定位/打开所在目录）与打开。
- 支持检测进度（百分比 + 当前文件名）与取消；结果在目录切换/重新扫描后失效清空。
- 哈希结果本版本不持久化（文件可变），每次检测实时计算；可在文档中记录该取舍。

## 交互与行为定义

- 入口：工具栏"检测重复"按钮（或更多菜单），仅当当前有扫描结果时可用。
- 流程：点击 → 主进程开始检测 → 面板显示进度（处理中 xx%）→ 完成显示分组结果；可随时取消。
- 分组规则：
  1. 按文件大小分组；仅大小相同的文件进入下一步（大小不同必不重复）。
  2. 组内文件数 ≥ 2 才做哈希。
  3. 哈希：流式分块（如 8 MiB 块）MD5；可先比"首块哈希"预筛（首块不同则内容必不同，跳过整文件哈希），再全量确认。预筛能显著减少大视频的读取量。
- 展示：按组列出，组标题显示重复文件数与本组总占用（`(N-1) × size` 可释放量提示，仅提示不执行）；行内右键：打开、打开所在目录、在文件夹树中定位、复制路径。
- 检测中用户切换根目录/重新扫描：取消进行中的检测并清空结果。
- 空结果（无重复）给出明确"未发现重复文件"状态，不是空白面板。
- 并发：哈希并发数上限（如 2-4），避免 IO 风暴；可用文件大小预估进度（按字节数算百分比更平滑）。

## 本版本只做

1. 主进程检测模块：大小分组 → 首块预筛 → 流式全量哈希 → 分组输出；进度事件与取消。
2. 检测面板 UI：进度、结果列表、空状态、右键操作。
3. 工具栏入口与目录切换/重扫时的失效清理。
4. 检测模块纯逻辑单测（分组、预筛、取消、异常文件跳过）。

## 本版本不做

- 不做删除、移动、合并、批量清理重复文件（任何写操作）。
- 不做近似重复 / 感知哈希 / 相似度排序。
- 不做跨根目录全局检测（仅当前扫描上下文）。
- 不持久化哈希结果，不做增量复用。
- 不把重复状态写入 VideoItem 缓存。
- 不做"同系列不同清晰度"这类语义重复识别。

## 涉及模块建议

- `electron/dup-detector.ts`：检测状态机、分组、分块哈希、进度与取消。
- `src/shared.ts`：重复组/检测进度/结果类型。

- `docs/`：检测行为与性能记录（大目录样例）。

## 实现要求

- 哈希用 Node 内置 `crypto.createHash` 流式处理；读取失败（无权限/被占用）的文件跳过并计入警告列表，不中断检测。
- 检测不阻塞主进程事件循环：大文件读取分块 + 适当让出（或 worker 线程，若已有 worker 基础设施则优先复用）。
- 进度节流推送（~200ms 或每 1%）。
- 取消语义：检测中取消立即停止读取并丢弃中间结果。
- 组内排序稳定（按路径字母序）；结果总占用提示计算正确。
- 预筛实现必须保证正确性：首块相同才继续全量；任何阶段失败的文件不得误判为重复。

## 验收标准

- 构造含重复对（同大小同内容）、同大小不同内容、仅文件名不同、不同大小文件的样本目录，分组结果全部正确。
- 大文件（≥1GB）检测有进度且可取消；取消后无残留状态、不阻塞后续操作。
- 权限受限文件被跳过并可见警告，检测继续完成。
- 检测中切换目录或重扫：结果清空、任务取消。
- 无重复时显示明确空状态；有重复时显示组、数量与可释放提示。
- 面板右键四项操作可用。
- `npm run typecheck`、`npm run build`、相关单测通过。
