# v0.8 详情增强 Prompt（编码 / 码率 / 帧率 / 音轨）

规划与提示词：DeepSeek-V4 Flash（agent: opencode），2026-08-23。

## 背景

你是一名资深 Electron + React + TypeScript 桌面应用工程师。请在现有 Vid Folder Browser 项目上进行 v0.8 增量开发。

当前元信息仅含：时长、分辨率、大小、修改时间。本版本扩展 ffprobe 解析深度，展示编码、码率、帧率、音轨、容器格式等技术信息，并打好 ffprobe 深度解析层，供后续版本（ffmpeg 依赖、重复检测）复用。

重要规则：

- 开始前阅读 `PROJECT_MEMORY.md`、`PROMPT_VERSIONING.md`、v0.7 Prompt、README 和当前实现。
- 沿用 v0.4 的错误模型（ErrorCategory / ItemError）、缓存自愈规则与 v0.5 组件体系。
- 解析失败不得影响既有字段与浏览行为，全部新字段按"未知"兜底。
- 中文内容和源码统一使用 UTF-8。

## 当前已实现功能

- v0.1-v0.7 全部能力：扫描、封面/元信息缓存与自愈、错误分类、shadcn/ui、文件夹树、快速访问、网格/列表悬停预览、播放进度记忆（v0.7）。
- 元信息通过 `ffprobe` 读取：时长、分辨率（宽高）；缓存到 `metadata-cache.json`。

本版本的重新实现目标：无（纯增量扩展）。

## 本版本目标

- 为每个视频读取并缓存技术信息：视频编码（codec/profile/level）、码率（容器级与视频流级）、帧率、音轨列表（codec/声道/采样率/语言）、容器格式。
- 详情面板展示可折叠"技术信息"区块；列表视图可选新增"编码"列。
- 解析层独立、可单测，供后续版本复用。

## 交互与展示定义

- 详情面板：在现有基础详情下方新增"技术信息"折叠区块（默认折叠），字段为键值对：
  - 容器：`MP4 (isom)`、`Matroska` 等（format_name + 可选 format_long_name）。
  - 视频编码：`H.264 (High, L4.1)`（codec_name + profile + level）；未知显示"未知"。
  - 码率：容器总码率与视频流码率（kbps，复用现有大小格式化风格）；缺失时可由"文件大小/时长"估算并标注"估算"。
  - 帧率：`23.98 fps`（优先 avg_frame_rate，回退 r_frame_rate；处理 0/0 与未定义）。
  - 音轨：每条一行 `AAC 2声道 44.1kHz`，无音轨显示"无音轨"。
- 列表视图：设置中新增可选开关"显示编码列"（持久化，默认关），显示视频编码短名（如 `h264`、`hevc`）。
- 元信息缓存结构扩展新字段；旧缓存缺少新字段时显示"未知"，重扫时自然补全，**不做全量缓存失效**。

## 本版本只做

1. `ffprobe -show_streams -show_format` 解析扩展（参数数组传递，保留中文/空格/特殊字符路径支持）。
2. 新字段类型、缓存读写与旧缓存兼容（可选字段 + 默认值）。
3. 详情面板"技术信息"区块与空值兜底。
4. 列表视图"编码"列（设置开关 + 持久化）。
5. 解析纯函数模块化并编写单测（帧率换算、码率格式化、profile/level 拼接、估算码率）。
6. README 与文档更新。

## 本版本不做

- 不做封面、截图、波形、音轨切换或内嵌字幕提取。
- 不做编码转换、转码、remux。
- 不做按编码/码率/帧率筛选（可后续扩展，本版不做）。
- 不引入数据库，不改变元信息缓存失效策略。
- 不内置或自动下载 ffmpeg（v0.9）。
- 不重构 UI 体系或扫描流程。

## 涉及模块建议

- `src/shared.ts`：扩展 VideoItem / 缓存记录类型（可选字段）。
- 解析模块（建议 `electron/media-info.ts` 或现有 ffprobe 模块扩展）：show_streams/show_format 解析、帧率换算、码率估算。
- `electron/main.ts`：enrichItem 元信息阶段接入新解析，失败仅置空新字段。
- 详情面板组件：技术信息折叠区块。
- 列表视图组件与设置：编码列。
- `lib/`：帧率/码率/编码字符串格式化纯函数。
- `docs/`：字段与解析行为说明。

## 实现要求

- 解析不得因单字段失败而丢弃整条元信息；ffprobe 输出结构差异（版本不同）全部兜底。
- 帧率换算：`a/b` 转为带两位小数的 fps，`0/0` 与负数视为未知。
- 码率估算仅当流级 bit_rate 缺失时使用，并明确标注"估算"。
- 缓存写入节流与现有策略一致；新字段不破坏旧记录读取。
- 单测覆盖：帧率、码率格式化、profile/level 拼接、异常 JSON、旧缓存兼容。

## 验收标准

- 正常视频显示完整技术信息（容器、编码、码率、帧率、音轨）。
- 无音轨视频、异常视频、ffprobe 输出缺失字段时均按"未知"显示且不报错。
- 详情面板折叠区块可展开/收起；列表"编码"列开关持久化。
- 旧缓存读取不抛错，重扫后新字段自然补全。
- 元信息阶段失败不影响封面生成（与 v0.4 解耦行为一致）。
- 中文路径、空格路径、特殊字符路径正常。
- `npm run typecheck`、`npm run build`、相关单测通过。
