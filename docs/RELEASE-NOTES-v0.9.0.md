# Vid Folder Browser v0.9.0 Release Notes

> 2026-09-05 · Windows x64

## 依赖自动管理

本版本解决"解压即用"的最大门槛：不再要求用户自行安装并配置 `ffmpeg` / `ffprobe`，应用可自动探测、缺失时在应用内一键下载安装。

1. **智能探测**：按 应用内版本 → 手动指定路径 → 系统 PATH → 常见安装位置（`C:\ffmpeg`、Program Files、Scoop、Chocolatey、WinGet）顺序自动探测，结果持久化，失效自动重探；状态栏徽标细化显示来源与版本（如"ffmpeg 应用内 n8.1.2"），点击打开依赖管理面板。
2. **按需下载**：依赖缺失时提示条出现"下载 ffmpeg"按钮（不自动下载，始终需用户确认），在应用内下载固定版本的 [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) win64 构建（约 76 MB），全程显示进度与速度，支持取消与失败重试；关闭面板不中断下载。
3. **安全校验**：下载完成后与内置 SHA-256 清单比对，不一致立即清理全部内容并明确报错"校验失败，可能被篡改或源变更"；解压路径双重防 zip-slip 校验；下载 URL 由主进程常量生成，渲染进程不可注入。
4. **版本切换**：依赖管理面板可查看各工具来源、版本与路径；支持"恢复系统版本 / 启用应用内版本"切换（应用内文件保留）与手动指定 ffmpeg/ffprobe 路径。
5. **执行层统一**：所有 ffmpeg/ffprobe 调用统一走解析后的绝对路径，探测结果跨启动复用。

## 依赖

- `ffmpeg` / `ffprobe`：自动探测，缺失时可在应用内下载（不再强制要求预装）。
- **GPL 声明**：应用内下载的 ffmpeg 二进制来自 BtbN/FFmpeg-Builds（GPL v3 构建）。本项目不随安装包分发该二进制，仅在用户明确确认后下载安装到应用数据目录；来源与版本见应用内依赖管理面板。

## 已知限制

- 应用内下载仅支持 Windows x64；不做版本自动更新（可在依赖面板重复下载清单版本覆盖）。
- 缓存失效仍基于"路径 + 大小 + 修改时间"；无实时文件监控；首次扫描冷缓存较慢。
- 完全未装 ffmpeg、弱网下载中断等极端场景的实测记录见 `docs/v0.9-dependency-validation.md`。
