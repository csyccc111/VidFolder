# Vid Folder Browser v0.4.0

## 本版本定位

发布质量加固：不新增浏览功能，将应用从"功能可用"推进到"行为可解释、质量可验证、发布可重复"。

## 更新内容

1. 错误提示统一
   - 全部可预期错误按类别展示：依赖缺失、目录不可读、文件不可读、元信息读取失败、封面生成失败、缓存损坏等。
   - 用户界面显示简洁中文说明，技术详情（原始 stderr）仅在悬停时可见，不再直接铺在界面。
   - 单个视频的元信息失败与封面失败分开显示，不再互相覆盖、含义模糊。

2. 元信息与封面任务解耦
   - ffprobe 失败不再阻断可执行的封面生成；ffmpeg 失败不丢失已读取的时长与分辨率。
   - 右键"重新生成封面"只重试必要阶段，不破坏仍有效的元信息。

3. 扫描错误可见
   - 根目录不可读时明确提示扫描失败，不再误报为"扫描完成"或"没有视频"。
   - 子目录不可读时跳过该目录继续扫描，并给出可查看的警告摘要。
   - 取消扫描、目录为空、目录不可读三种状态明确区分。

4. 缓存可靠性
   - 缩略图缺失、零字节或损坏时自动降级并重新生成，应用不崩溃。
   - 元信息缓存（metadata-cache.json）损坏时自动备份原文件并安全回退，不影响启动。
   - 扫描完成后自动清理已失效记录与孤儿缩略图，仅操作应用自身缓存目录，不触碰用户视频文件。

5. 构建与发布
   - 安装包命名统一为 `Vid.Folder.Browser-<版本>-win-x64.zip`。
   - 新增四份质量文档：性能基准指南、缓存失效验证记录、发布冒烟清单、发布流程清单。

## 已知限制

- 依赖本机 `ffmpeg` 与 `ffprobe`，不内置、不自动下载。
- 缓存失效判断基于"路径 + 文件大小 + 修改时间"；三者均不变但内容变化时可能命中旧缓存（v0.4 明确接受的已知边界）。
- 首次扫描需为每个视频读取元信息并生成封面，耗时与视频数量正相关；二次扫描（热缓存）明显更快。
