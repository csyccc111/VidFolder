# v0.4 发布冒烟测试清单

版本：v0.4 | 编制：DeepSeek-V4 Flash，2026-08-10 | 执行人：用户自测

用途：**发布前人工验证**。可由不了解实现细节的人独立执行。全部通过才算冒烟通过。

## 准备

- 解压 `Vid.Folder.Browser-0.4.0-win-x64.zip` 到独立目录。
- 准备一个测试视频目录：含 ≥5 个视频（含中文名、空格名、特殊字符名、横屏与竖屏）、≥2 层子目录。
- 准备损坏文件：把一个 txt 改后缀为 `.mp4` 放入测试目录。

## A. 安装包与启动

- [ ] A1 解压后双击 `Vid Folder Browser.exe` 可正常启动，窗口出现
- [ ] A2 关闭应用（点窗口 ×）进程完全退出，无残留窗口
- [ ] A3 再次启动正常，无报错

## B. 扫描与浏览

- [ ] B1 空状态引导选择文件夹，选择测试目录后开始扫描
- [ ] B2 扫描过程中网格**增量出现**视频卡片（不等待全部完成）
- [ ] B3 扫描完成后状态栏显示视频总数、封面 N/M（M=总数）、失败 0
- [ ] B4 点"刷新"重新扫描正常
- [ ] B5 扫描过程中点"取消"（若存在该按钮）或关闭窗口，不崩溃；重新进入无异常
- [ ] B6 损坏 .mp4 文件不导致崩溃，显示为失败（详情面板有中文说明）

## C. 缓存

- [ ] C1 首次扫描（冷缓存）后关闭应用，重新打开自动加载上次文件夹
- [ ] C2 二次扫描（热缓存）明显更快，封面直接出现
- [ ] C3 修改一个视频文件（如重命名后再改回或替换内容），刷新后该视频封面重新生成

## D. 视图与交互

- [ ] D1 网格/列表切换正常，两种视图数据一致
- [ ] D2 列表视图点击表头（文件名/时长/大小/修改时间）排序正常，方向箭头正确
- [ ] D3 搜索关键词实时过滤
- [ ] D4 格式筛选、时长筛选、画面筛选各自生效且可组合
- [ ] D5 清除筛选恢复全量
- [ ] D6 左侧目录树显示累计数量，点击后只显示该目录及子目录视频，"全部视频"可返回
- [ ] D7 缩略图小/中/大切换生效（列表视图下禁用属正常）
- [ ] D8 关闭并重启应用后，视图模式/排序/缩略图大小被记住

## E. 右键菜单

- [ ] E1 "打开所在目录"在资源管理器中打开并选中该文件
- [ ] E2 "用默认播放器打开"能播放该视频
- [ ] E3 "复制完整路径"粘贴后为完整正确路径
- [ ] E4 "重新生成封面"后封面刷新且元信息（时长/分辨率）不被破坏

## F. 依赖缺失（临时把 ffmpeg/ffprobe 移出 PATH 后测，测完恢复）

- [ ] F1 仅缺 ffmpeg：顶部提示缺少 ffmpeg；已有缓存封面仍显示；新视频时长/分辨率可读取，封面显示失败文案而非崩溃
- [ ] F2 仅缺 ffprobe：顶部提示缺少 ffprobe；已有缓存元信息仍显示；封面仍可生成
- [ ] F3 两者都缺：应用可打开、可扫描、可浏览文件列表和已有缓存，不崩溃

## G. 异常与边界

- [ ] G1 根目录无权限（可对某目录设置只读/拒绝读取后选择它）：显示扫描错误而非"扫描完成/没有视频"
- [ ] G2 子目录无权限（仅某子目录设置拒绝读取）：其它视频正常，顶部出现警告摘要
- [ ] G3 损坏缓存：把 metadata-cache.json 改乱码后启动，应用正常回退，不崩溃
- [ ] G4 中文路径、空格路径、长文件名、特殊字符文件名均正常显示与操作
- [ ] G5 详情面板：选中视频显示完整路径、大小、时长、修改时间、分辨率；失败时错误为中文，技术详情悬停可见
