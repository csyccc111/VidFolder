# Vid Folder Browser v0.10.0 Release Notes

> 2026-11-19 · Windows x64

## 发布与更新

本版本主题是"发布与更新"：发布流程自动化、应用内更新检查、安装门面（图标 + 安装包）。不新增浏览功能。

1. **自动发布（CI）**：打 tag 即由 GitHub Actions 自动构建发布——typecheck / test / build 门禁 → zip + NSIS 双产物 → SHA-256 校验和写入构建摘要 → 以本文件全文为发布说明 → 发布后 API 核验资产完整性。另支持 dry_run 手动试跑（只构建校验，不发布）。
2. **应用内更新检查**：启动数秒后静默检查 GitHub 最新版本（默认开启，可在更新对话框关闭）；工具栏新增"检查更新"按钮，随时手动检查（不受开关限制）。发现新版时对话框显示版本号与更新摘要，引导打开下载页；支持"忽略此版本"（持久化，后续不再提示该版本）。**只提示、不自动下载替换**，是否升级始终由用户决定。
3. **NSIS 安装包**：新增 `Vid.Folder.Browser-Setup-<版本>-win-x64.exe`，向导式安装、可自选安装目录、per-user 安装（无需管理员权限）；与 zip 便携版并行提供，任选其一。
4. **应用图标**：全新图标（暗色圆角底 + 蓝渐变文件夹 + 白色播放三角），统一应用于窗口、任务栏、安装包与桌面快捷方式；16px 小尺寸下仍可辨识。

## 依赖

- `ffmpeg` / `ffprobe`：要求与 v0.9 相同——自动探测，缺失时可在应用内一键下载（约 76 MB）。
- **GPL 声明**：应用内下载的 ffmpeg 二进制来自 BtbN/FFmpeg-Builds（GPL v3 构建）。本项目不随安装包分发该二进制，仅在用户明确确认后下载安装到应用数据目录；来源与版本见应用内依赖管理面板。

## 已知限制

- 更新检查只提示、不自动更新；需手动下载新版 zip 覆盖或运行新版安装包。
- 更新检查依赖 GitHub API 可达；网络受限或 API 限流时静默失败，不影响浏览。
- 大目录（数千视频）的全量渲染性能问题仍存在，计划 v0.11 以虚拟滚动解决。
- 缓存失效仍基于"路径 + 大小 + 修改时间"；无实时文件监控；首次扫描冷缓存较慢。

## 验证

- 单元测试 67 项全通过（新增 semver 语义比较等纯逻辑测试）。
- v0.10 冒烟 7 项（更新对话框全状态：最新 / 有新版 / 已忽略 / 出错 / 已关闭，真实 Electron）+ 既有三套冒烟（v0.5 DOM 18 项、v0.8 详情 14 项、v0.9 依赖 9 项）回归全通过。
- 本地 zip + NSIS 双产物构建验证通过；`npm run typecheck` / `npm run build` 通过。

## 升级说明

- zip 便携版用户：解压覆盖即可，设置与缓存兼容，无需手动迁移。
- 安装包用户：运行 Setup 向导安装；后续版本重新运行新版安装包即可覆盖安装。
- 更新检查默认开启，升级后首次启动会静默检查一次；如不希望检查，可在更新对话框关闭"启动时自动检查"。
