# Vid Folder Browser v0.6.0

> 自 v0.3.0 后的首个新版本，包含 v0.4（发布质量加固）、v0.5（界面体系、文件夹树与快速访问）、v0.6（悬停多帧预览）三阶段改动。

## 更新内容

### 悬停多帧预览（v0.6）

1. **悬停即看**：网格视图中鼠标悬停封面约 0.4 秒后，自动沿时间轴播放该视频的 8 个代表帧，帮助快速判断内容；鼠标水平移动切换帧，角标显示当前帧时间；离开后立即恢复主封面。
   - 一次调用生成全部帧，冷生成平均约 168ms；帧缓存命中仅约 7ms。
   - 仅网格视图启用；工具栏可随时开关（状态持久化），未检测到 ffmpeg 时自动禁用并提示。

2. **按需生成，零预扫负担**：仅在悬停确认需要时才生成帧，不影响首次扫描速度；不足 1 秒的视频自动减少帧数；生成失败自动回退静态封面，不影响浏览。

3. **独立缓存与容量治理**：帧缓存与主封面缓存完全独立，上限 512 MiB，超出后按近似 LRU 整组淘汰；单组帧缺失或损坏时自动整组重建。

4. **响应式调度**：生成队列并发 1、排队上限 8，同视频请求自动合并；快速移开即取消，运行中的生成结果不会串位；退出应用时安全清理后台进程。

### 新界面与组件体系（v0.5）

5. **统一组件体系**：接入 shadcn/ui（Tailwind CSS + Radix），工具栏、下拉、菜单、提示、滚动、弹层等基础组件全部统一；整体重新设计为紧凑、克制的工作导向暗色界面。

6. **层级文件夹树**：左侧按真实目录层级展示视频文件夹，替代原扁平列表；显示直接视频数与累计视频数；支持展开/折叠、名称过滤、一键全部折叠、右键"在资源管理器中打开"、完整键盘导航。

7. **快速访问**：自动记录最近成功打开的文件夹（最多 10 条），可固定常用文件夹（固定项不淘汰）；失效路径标记提示、可移除记录；支持从资源管理器拖入单个文件夹打开。

8. **高频浏览与布局**：双击用默认播放器打开；网格/列表方向键移动、`Enter` 打开、`Ctrl+C` 复制路径、详情面板"在文件夹树中定位"；左侧栏可折叠、拖拽调宽，右侧详情可收起，窄窗口自动切换侧滑覆盖层；布局与展开状态持久化。

### 质量加固（v0.4）

9. **错误提示统一**：全部可预期错误按类别展示，界面显示简洁中文说明，技术详情仅在悬停时可见。
10. **元信息与封面任务解耦**：ffprobe 失败不阻断封面生成，ffmpeg 失败不丢失已读取的时长与分辨率。
11. **扫描错误可见**：根目录不可读明确报错；子目录不可读跳过并给出警告摘要；取消/为空/出错三态明确区分。
12. **缓存可靠性**：缺失或损坏的缩略图自动重新生成；元信息缓存损坏时自动备份并安全回退；扫描后只清理应用自身缓存内的失效记录与孤儿缩略图，不触碰用户视频。

## 已知限制

- 依赖本机 `ffmpeg` 与 `ffprobe`，不内置、不自动下载；缺失时仍可浏览已有缓存，悬停多帧预览自动禁用。
- 缓存失效判断基于"路径 + 大小 + 修改时间"；三者均不变但内容变化时可能命中旧缓存（已接受的边界）。
- 首次扫描需逐视频读取元信息并生成封面，耗时与视频数量正相关；二次扫描（热缓存）明显更快。
- 不提供实时文件监控，文件夹内容变化后需手动刷新。
