# v0.7 列表悬停预览验证记录

实施：DeepSeek-V4 Flash（agent: DeepSeek Harness），2026-08-23。

> 说明：v0.7 原规划的"播放进度记忆"已按用户要求移除（认为意义不大），本记录只覆盖列表悬停预览。

## 实现要点

- **复用 v0.6 链路**：主进程预览（抽帧/缓存/队列/LRU/取消）零改动；前端通过 `handlePreviewStart / handlePreviewLeave` 与网格共用同一个 `previewSession` 状态，天然互斥（同一时刻全局只有一个可见预览会话）。
- **行内状态机**：`pointerover` 后 400ms 延迟激活（复用 `PREVIEW_ACTIVATE_DELAY_MS`）；`pointerout` 后 200ms 延迟关闭（浮层是行子元素，移入浮层不触发离开）；会话被其他行接管时立即恢复。
- **胶片预览条**：`FilmstripPreview` 浮层（绝对定位，不推动行布局），8 帧一排（80×48），当前帧 `ring` 高亮，底部显示帧时间；帧映射优先按浮层区域计算（60ms 节流），浮层未渲染时退回整行宽度。
- **关闭时机**：滚动（main onScroll）、键盘方向键、排序/筛选/视图/目录变化（`listInvalidateKey` effect）都立即取消请求并关闭浮层；滚动中不会创建新预览任务（400ms 延迟保证）。
- **列表行缩略图**：行首新增 64×36 小缩略图（thumb:// 协议），作为悬停预览载体；表格容器由 `overflow-hidden` 改为圆角保留、内容可见，避免裁剪浮层。
