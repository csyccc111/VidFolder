# Vid Folder Browser v0.8.0 Release Notes

> 2026-08-23 · Windows x64

## 技术详情增强

1. **详情面板"技术信息"区块**：基础详情下方新增可折叠区块（默认收起），展示容器格式（如 `MP4 (isom)`、`Matroska`）、视频编码（如 `H.264 (High, L4.1)`）、容器/视频流码率（容器级缺失时按大小与时长估算并标注"估算"）、帧率、音轨列表（编码/声道/采样率/语言）。
2. **列表"编码"列**：工具栏"筛选"面板内新增"显示编码列"开关（持久化，默认关），显示视频编码短名（`h264`、`hevc` 等）。
3. **解析层独立**：基于 `ffprobe -show_streams -show_format` 的新解析模块，纯函数、可单测，供后续版本复用；参数数组传递，中文/空格路径不受影响。
4. **失败隔离与兜底**：单字段缺失按"未知"显示、无音轨显示"无音轨"，不报错；解析失败不影响既有字段与封面生成。
5. **旧缓存兼容**：旧缓存缺技术字段时显示"未知"，重扫自动补全（仅重新探测元信息，缩略图复用，不做全量失效）。

## 依赖

- 不变：依赖本机 `ffmpeg` 与 `ffprobe`（缺失时浏览已有缓存不受影响，悬停预览自动禁用）。

## 已知限制

- 同 v0.7：依赖本机 ffmpeg/ffprobe、缓存按"路径+大小+修改时间"失效、无实时文件监控、首次扫描冷缓存较慢。
- 音轨语言按 ffprobe 的 `tags.language` 显示；无标签或 `und` 时不显示。

## 验证

- 单元测试 59 项全通过（新增 16 项媒体信息解析测试）。
- v0.8 冒烟 15 项（真实 ffmpeg/ffprobe）+ v0.7 回归 7 项 + v0.6 回归 14 项 + v0.5 DOM 回归 18 项全通过。
- `npm run typecheck` / `npm run build` 通过。

详见 `docs/v0.8-detail-validation.md`。
