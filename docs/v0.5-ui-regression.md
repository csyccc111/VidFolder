# v0.5 UI 重构回归记录

实施：DeepSeek-V4 Flash，2026-08-13。

## 改造前基线（v0.4 工作流）

- 单一 `App.tsx`（约 620 行）承载工具栏、筛选、侧栏目录列表、网格/列表、详情、状态栏、右键菜单全部状态与渲染。
- 左侧目录为扁平列表，按相对路径字典序排序，无层级、无展开/折叠、无搜索。
- 无最近/固定文件夹、无拖入文件夹、无键盘操作、无布局持久化。
- 样式全部位于 `src/styles.css`，无组件体系。

## 改造后结构

- `src/components/ui/`：shadcn/ui 基础组件（由 CLI 加入并由项目维护）。
- `src/components/layout/`：`sidebar.tsx`（快速访问 + 文件夹树 + 折叠/调宽）。
- `src/components/folder/`：`folder-tree.tsx`（层级树、过滤、键盘）、`quick-access.tsx`（最近/固定）。
- `src/components/browser/`：`toolbar.tsx`、`video-card.tsx`、`video-grid.tsx`、`video-list.tsx`、`empty-state.tsx`。
- `src/components/details/`：`detail-panel.tsx`（面板/Sheet 双形态）。
- `src/components/status/`：`status-bar.tsx`、`scan-notices.tsx`。
- `src/lib/`：`path.ts`、`tree.ts`、`history.ts`、`filter.ts`、`format.ts` 纯逻辑模块 + 单测。
- `App.tsx` 收敛为状态编排与顶层布局（约 560 行）。
