# Vid Folder Browser v0.8.1 Release Notes

> 2026-09-04 · Windows x64

## 悬停预览移除

本版本为纯移除版本，无新增功能：应用整体移除 v0.6 / v0.7 引入的"悬停多帧预览"（悬停视频约 400ms 后生成并展示 8 帧胶片预览），只保留静态封面。移除原因是实际使用中悬停预览明显卡顿，影响浏览体验。

1. **移除内容**：网格/列表的悬停预览浮层、按需抽帧（一次 ffmpeg 调用出 8 帧）、`preview://` 协议、独立预览缓存（512 MiB LRU 治理）、工具栏悬停预览开关与预览缓存管理面板、相关 IPC 与设置项。
2. **保留内容**：网格静态封面、列表行内 64×36 封面缩略图、右键"重新生成封面"，均走原有封面缓存链路，不受影响。
3. **遗留数据清理**：启动时自动删除旧版本遗留的 `preview-cache/` 目录；`settings.json` 中残留的悬停预览开关键为惰性数据，应用不再读取。

## 依赖

- 不变：依赖本机 `ffmpeg` 与 `ffprobe`（缺失时浏览已有缓存不受影响，新视频封面/元信息无法生成）。

## 已知限制

- 同 v0.8：依赖本机 ffmpeg/ffprobe、缓存按"路径+大小+修改时间"失效、无实时文件监控、首次扫描冷缓存较慢。

## 验证

- 单元测试 49 项全通过（随预览纯逻辑测试一并移除，自 59 项减少）。
- `npm run typecheck` / `npm run build` 通过。
- v0.8 冒烟脚本（详情技术区块 + 列表编码列，真实 ffmpeg/ffprobe）回归通过。

## 升级说明

- 直接解压覆盖使用；无需迁移数据。
