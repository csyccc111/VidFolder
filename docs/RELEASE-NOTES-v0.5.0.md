# Vid Folder Browser v0.5.0

> 自 v0.3.0 后的首个新版本：包含 v0.4（发布质量加固）与 v0.5（界面体系、文件夹树与快速访问）两阶段改动。

## 更新内容

### 新界面与组件体系（v0.5）

1. **统一组件体系**
   - 接入 shadcn/ui（Tailwind CSS + Radix），工具栏、下拉、菜单、提示、滚动、弹层等基础组件全部统一。
   - 整体重新设计为紧凑、克制的工作导向暗色界面，长文件名、长路径不再溢出控件。

2. **层级文件夹树**
   - 左侧按真实目录层级展示视频文件夹，替代原扁平列表。
   - 每个文件夹显示直接视频数与包含子文件夹的累计视频数。
   - 支持展开/折叠（与选择互不误触）、按名称过滤、一键全部折叠、右键"在资源管理器中打开"。
   - 完整键盘导航：方向键移动、左右展开/折叠、Enter 选择；选中节点自动展开祖先并保持可见。

3. **快速访问**
   - 自动记录最近成功打开的文件夹（最多 10 条，按时间排序、路径去重），可固定常用文件夹（固定项不淘汰）。
   - 失效路径标记提示、可随时移除记录，不影响启动、不触碰文件系统。
   - 从资源管理器直接拖入单个文件夹即可打开。

4. **高频浏览与布局**
   - 双击卡片/行用默认播放器打开；网格/列表内方向键移动选择；`Enter` 打开；`Ctrl+C` 复制路径；详情面板支持"在文件夹树中定位"。
   - 左侧栏可折叠并可拖拽调宽，右侧详情面板可收起；窄窗口下详情自动切换为侧滑覆盖层。
   - 树展开状态、侧栏与详情栏状态持久化，重启后恢复。

### 质量加固（v0.4）

5. **错误提示统一**：全部可预期错误按类别展示，界面显示简洁中文说明，技术详情仅在悬停时可见。
6. **元信息与封面任务解耦**：ffprobe 失败不阻断封面生成，ffmpeg 失败不丢失已读取的时长与分辨率。
7. **扫描错误可见**：根目录不可读明确报错；子目录不可读跳过并给出警告摘要；取消/为空/出错三态明确区分。
8. **缓存可靠性**：缺失或损坏的缩略图自动重新生成；元信息缓存损坏时自动备份并安全回退；扫描完成后只清理应用自身缓存内的失效记录与孤儿缩略图，不触碰用户视频。

## 已知限制

- 依赖本机 `ffmpeg` 与 `ffprobe`，不内置、不自动下载；缺失时仍可浏览已有缓存。
- 缓存失效判断基于"路径 + 大小 + 修改时间"；三者均不变但内容变化时可能命中旧缓存（已接受的边界）。
- 首次扫描需逐视频读取元信息并生成封面，耗时与视频数量正相关；二次扫描（热缓存）明显更快。
- 不提供实时文件监控，文件夹内容变化后需手动刷新。
