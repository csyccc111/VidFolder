# Vid Folder Browser v0.7.0 Release Notes

> 2026-08-23 · Windows x64

## 列表悬停预览

列表视图中鼠标悬停行约 0.4 秒，行下方即浮出横向胶片预览条——8 帧一排，水平移动鼠标切换帧并高亮当前帧，底部实时显示帧时间；移出约 200ms 自动关闭。滚动、键盘操作、排序或筛选变化时预览立即关闭。网格与列表共用同一预览会话，同一时刻只有一个预览可见；列表行新增小缩略图作为预览载体。完全复用 v0.6 的抽帧、缓存与取消机制，扫描与预览性能不受影响。

> 原规划的"播放进度记忆"经评估对浏览场景价值有限，已按用户要求移除，不进入本版本。

## 依赖

- 不变：依赖本机 `ffmpeg` 与 `ffprobe`（缺失时浏览已有缓存不受影响，悬停预览自动禁用）。

## 已知限制

- 同 v0.6：依赖本机 ffmpeg/ffprobe、缓存按"路径+大小+修改时间"失效、无实时文件监控、首次扫描冷缓存较慢。

## 验证

- 单元测试 43 项全通过。
- v0.7 列表预览冒烟 7 项 + v0.5 DOM 回归 18 项 + v0.6 预览回归 14 项全通过。
- `npm run typecheck` / `npm run build` 通过。

详见 `docs/v0.7-browse-validation.md`。
